# CampusFlow
Timetable manager: console program (C++) + website (single HTML file).

## Console (main.cpp)
    g++ -std=c++17 -O2 main.cpp -o campusflow
    ./campusflow          # timetable.csv must be in the same folder

## Website
Open `campusflow.html` in any browser. No install, no internet needed.

## DSA used
Linked list, stack (undo), linear + binary search, bubble/merge/quick sort,
recursion, backtracking (planner), binary search tree (website).
